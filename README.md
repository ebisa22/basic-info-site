# Basic Info Site

A simple multi-page website built with HTML, CSS, and Node.js to practice handling routes and serving files with the built-in HTTP module.

## Pages

- `/` — Home page
- `/about` — About page
- `/contact-me` — Contact page
- Any unknown route displays the 404 page.

## Technologies

- HTML
- CSS
- Node.js

## Getting Started

1. Make sure Node.js is installed.
2. Clone this repository.
3. Navigate to the project directory.
4. Start the server:

```
   node index.js
```

5. Open `http://localhost:8080` in your browser.

## What I Learned

- Creating an HTTP server with Node.js.
- Handling URL routes.
- Reading and serving HTML and CSS files.
- Handling unknown routes with a custom 404 page.
